NAME

code-review-skill — A modular code review skill for Claude Code, focused on JavaScript/TypeScript, Node.js, NestJS, Python, and Salesforce

SYNOPSIS

Use code-review-skill to review this PR
Use code-review-skill to review this <Apex class | LWC | flow | Node service>
Use code-review-skill for [security | performance | architecture] review

DESCRIPTION

A code review procedure for Claude: resolve the change, load only the matching guides, verify every finding against the code, and report in a fixed format.

Core is only ~160 lines; every guide opens with a review checklist that doubles as its table of contents, so a review reads the checklists and opens only the sections the diff touches. Covers JavaScript, TypeScript, Node.js, NestJS, Python, and Salesforce (Apex, triggers, SOQL/SOSL, LWC, Aura, Visualforce, Flows, metadata).

Every finding carries a severity label, a file:line, its impact, and a fix. Every review follows six steps: resolve target · triage · load guides · review · verify · report.

WORKFLOW

  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ resolve  │ ─▶ │  triage  │ ─▶ │  guides  │ ─▶ │  review  │ ─▶ │  verify  │ ─▶ │  report  │
  └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
1. resolve the target
A PR (gh pr view / gh pr diff), a branch against its base, or uncommitted work plus untracked files.
2. triage
Large diffs go through pr-analyzer.py: risk factors and the guides to load. Riskiest files first.
3. load guides
Each guide's review checklist first, then only the sections whose patterns appear in the diff.
4. review
Correctness · security · performance and limits · error handling · tests · reuse.
5. verify
Every candidate finding is checked against the code; what can't be confirmed statically becomes a question.
6. report
Verdict · scope · findings (severity, file:line, impact, fix) · questions.

SEVERITY

  • ● [blocking] must fix — resolve before merge; security / correctness / serious logic
  • ● [important] should fix — strongly recommended; discuss if you disagree
  • ● [nit] nice to have — style or preference; non-blocking
  • ● [suggestion] alternative — worth considering; author decides

INSTALLATION

Install with npx skills for mainstream agents, or clone into the Claude Code skills directory.

# npx skills (Cursor / Claude Code / Codex / OpenCode / others)
$ npx skills add RAMukhamadeev1/cti-code-review-skill

# or clone into the Claude Code skills directory — macOS / Linux
$ git clone https://github.com/RAMukhamadeev1/cti-code-review-skill.git \
    ~/.claude/skills/code-review-skill

# Windows PowerShell
PS> git clone https://github.com/RAMukhamadeev1/cti-code-review-skill.git `
       "$env:USERPROFILE\.claude\skills\code-review-skill"

EXAMPLES

  • Use code-review-skill to review this PR resolves the diff, loads guides checklist-first, verifies every finding
  • Review this Apex trigger loads salesforce/platform.md + apex-triggers.md + apex.md · bulk safety · recursion
  • Review this Lightning Web Component loads salesforce/lwc.md + javascript.md · Apex contract · XSS · cleanup
  • Security review of this Node.js service loads nodejs.md + javascript.md + security-review-guide.md
  • Architecture review loads the architecture guide · SOLID · anti-patterns · coupling
